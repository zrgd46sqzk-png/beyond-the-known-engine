# دليل المتابعة من الآيفون

## الحالة
المستودع عام ويحتوي الآن على ملفات بداية الواجهة. لم يتم نشر الموقع بعد، ولم يتم إنشاء قاعدة بيانات أو ربط حسابات التواصل.

## الخطوة التالية: Vercel
1. افتح https://vercel.com/new من الآيفون.
2. سجّل الدخول باستخدام GitHub.
3. اختر المستودع `zrgd46sqzk-png/beyond-the-known-engine`.
4. اترك إعدادات Next.js الافتراضية، ثم اضغط Deploy.
5. إذا ظهرت أخطاء بناء، لا تغيّر إعدادات عشوائية؛ أرسل لقطة شاشة للخطأ.

## قاعدة البيانات لاحقًا
افتح https://supabase.com/dashboard وأنشئ مشروعًا جديدًا. لا تضع كلمات مرور أو مفاتيح سرية في محادثة ChatGPT أو في مستودع GitHub العام. ملف `supabase/schema.sql` هو مخطط أولي يحتاج مراجعة واختبارات أمنية قبل استخدامه مع بيانات حقيقية.

## قبل النشر الحقيقي
- إعداد تسجيل الدخول والصلاحيات وفصل بيانات كل مساحة عمل.
- تنفيذ سجل تدقيق للموافقات.
- الموافقة يجب أن ترتبط بنسخة محددة من الفيديو والسكريبت والكابشن والوجهة.
- أي تعديل يلغي الموافقة السابقة.
- لا تفعّل النشر الآلي قبل تطبيق قفل موافقة خادمي واختباره.
